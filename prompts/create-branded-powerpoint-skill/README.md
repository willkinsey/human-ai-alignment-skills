# Create a Branded PowerPoint Skill

Turn an approved PowerPoint template into a reusable skill that creates editable, on-brand first-draft decks.

## Use It

1. Open a local, file-capable coding agent such as Codex or Claude Code.
2. Provide the approved `.pptx` template and the original, approved logo file.
3. Copy and paste [PROMPT.md](PROMPT.md) into a new session.
4. Review the generated test deck and renders before using the resulting skill.

The prompt is designed for a few common slide types, not an entire corporate template library. Use the original PowerPoint and logo; a PDF alone can be a useful visual reference, but it cannot verify editable structure, exact content slots, or canonical assets.
